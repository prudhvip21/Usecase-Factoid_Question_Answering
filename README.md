# Factoid Question Answering

Decide whether a candidate sentence answers a factual question.

## Approach

- Named entity matching between question and sentence with spaCy
- Baseline and final models using Naive Bayes and Random Forest

## Results

Accuracy between about 0.74 and 0.80 in the saved notebook output.
